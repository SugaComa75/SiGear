Prototype Plan — Hub & Apps (Sprint 1)

Goals (6 weeks):
- Basic Hub prototype that enforces DNS policy and reports local logs
- Mobile app skeleton: VPN connection, safe-view stub, SOS button
- Minimal Cloud moderation stub: ingestion endpoint + simple web UI for human review
- Parent Dashboard mock: user profiles and alerts view

Tasks by week:
- Week 1: Board selection, toolchain, repo structure, Hub OS image baseline
- Week 2: Implement DNS policy service on Hub; basic web UI for Dashboard mock
- Week 3: Mobile app VPN stub and safe-view renderer; SOS event flow end-to-end
- Week 4: Cloud ingestion API + basic classifier (rule-based) + human review UI
- Week 5: Integration, e2e testing in lab, telemetry capture
- Week 6: Pilot prep, documentation, consent forms

Deliverables:
- Flashable Hub image (dev board)
- Mobile app APK/IPA dev build
- Cloud moderation endpoint and Dashboard prototype
- Pilot onboarding guide
