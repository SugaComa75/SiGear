# Contributor Code of Conduct

This project is dedicated to building an open, transparent, and safety‑focused digital ecosystem.
To maintain a healthy and respectful environment, all contributors, maintainers, and community members are expected to follow this Code of Conduct.

## Our Values
We commit to creating a community that is:
- Open — Anyone can contribute, review, or audit the project.
- Respectful — We treat each other with professionalism and empathy.
- Transparent — All decisions, discussions, and contributions are documented.
- Safety‑Focused — User protection, privacy, and ethical design are non‑negotiable.
- Collaborative — We work together to build something meaningful and trustworthy.

## Expected Behaviour
All participants are expected to:
- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Provide constructive feedback
- Prioritise user safety, privacy, and transparency in all contributions
- Document behaviour, logic, and design decisions clearly
- Follow the project’s licensing requirements (AGPLv3)
- Report issues responsibly and respectfully

## Unacceptable Behaviour
The following behaviours are not tolerated:
- Harassment, discrimination, or personal attacks
- Dismissive or hostile communication
- Introducing or advocating for hidden, undocumented, or deceptive system behaviour
- Attempting to add proprietary, closed‑source, or licence‑incompatible components
- Misrepresenting the project’s goals or safety principles
- Sharing sensitive information without consent
- Any behaviour that undermines trust, transparency, or auditability

## Safety & Transparency Requirements
Because this project is built around user protection and auditability, contributors must:
- Ensure all code and documentation is fully transparent
- Avoid any “black box” logic or hidden functionality
- Document all changes, decisions, and assumptions
- Respect the AGPLv3 licence and its copyleft requirements
- Ensure contributions align with the project’s safety‑by‑design principles

## Reporting Issues
If you experience or witness unacceptable behaviour:
- Open a confidential issue (if supported)
- Or contact the maintainers directly via the project’s listed communication channels
Reports will be handled promptly, respectfully, and confidentially.

## Enforcement
Project maintainers are responsible for:
- Clarifying standards of acceptable behaviour
- Taking appropriate corrective action when violations occur
- Removing or rejecting contributions that violate this Code
- Temporarily or permanently banning contributors for repeated or severe violations

## Scope
This Code of Conduct applies to:
- All project spaces (GitHub, discussions, issues, PRs)
- External channels where the project is represented
- Interactions between contributors, maintainers, and community members

## Commitment
By participating in this project, you agree to uphold this Code of Conduct and contribute to a safe, transparent, and ethical open‑source ecosystem.
