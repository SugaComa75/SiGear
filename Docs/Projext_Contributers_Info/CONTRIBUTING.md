# Contributing to This Project

Thank you for your interest in contributing.
This project is built on transparency, safety, and community collaboration.

1. Ways to Contribute
- Improve documentation
- Build prototypes
- Review architecture
- Suggest safety improvements
- Develop components
- Participate in audits
- Provide UX/UI feedback

2. Contribution Rules
- All contributions are licensed under AGPLv3
- No proprietary or closed‑source components may be introduced
- All behaviour must be documented and auditable
- Safety and privacy considerations must be included in all proposals

3. How to Start
- Read the documentation in /concept and /docs
- Open an Issue to discuss your idea
- Submit a Pull Request when ready
