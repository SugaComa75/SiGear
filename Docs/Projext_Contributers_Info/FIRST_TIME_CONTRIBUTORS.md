# A Friendly Guide for New Contributors

* Welcome
* Thank you for your interest in contributing.
* This project is built on openness, transparency, and safety — and we’re glad you’re here.
* This guide will help you get started, understand the project, and make your first contribution confidently.

** Step 1: Understand the Project
Start by reading:
- /concept/ — the high‑level vision
- /docs/ — the detailed architecture, safety model, and governance
- README.md — the overview
- CONTRIBUTING.md — contribution rules
- CODE_OF_CONDUCT.md — behaviour expectations
This will give you a clear picture of what the project is and how it works.

** Step 2: Choose How You Want to Contribute
You can contribute by:
- Improving documentation
- Reviewing architecture
- Suggesting safety improvements
- Building prototypes
- Writing code
- Creating diagrams
- Testing components
- Providing UX/UI feedback
You don’t need to be an expert — all contributions are valued.

** Step 3: Opening an Issue
If you want to propose something:
- Go to Issues
- Choose the appropriate template (if available)
- Describe your idea clearly
- Link to relevant documents if needed
Issues are where discussions begin.

** Step 4: Making a Pull Request
When you’re ready to contribute:
- Fork the repository
- Create a new branch
- Make your changes
- Document everything clearly
- Submit a Pull Request (PR)
- Explain the reasoning behind your changes
Maintainers will review your PR and may request improvements.

** Safety & Transparency Requirements
All contributions must:
- Be fully documented
- Avoid hidden or undocumented behaviour
- Respect privacy and safety principles
- Follow the AGPLv3 licence
- Maintain auditability
- Align with the project’s mission
This ensures the system remains trustworthy.

** Getting Help
If you’re unsure about anything:
- Ask in the Issue you’re working on
- Start a new Issue with a question
- Read through existing discussions
The community is here to help.

** Your First Contribution
Once your first PR is merged:
- You’ll be listed as a contributor
- You’ll be part of the project’s history
- You’ll help build a transparent, safety‑first digital ecosystem
* Welcome aboard.
