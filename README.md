# SiGear Core Model

SiGear is a four‑layer system for identity and consent governance.

## Core Components
1. Governance Module – service‑side enforcement  
2. NTI + Avatar – policy‑carrying identity  
3. SiGear App  
4. HomeHub / SocialHub

## SiGear — Proof‑of‑Enforcement Prototype

SiGear is currently a proof‑of‑enforcement prototype for identity and consent governance.

The current build target is a **Docker‑hosted command‑line prototype**, not a full product implementation.

**Warning:**  
No component may define its own identity, consent, capability, lifecycle, or audit model.  
All implementations must use the shared contracts in `/contracts`.

---

## Project Overview

SiGear is an open‑source, fully auditable digital safety and identity framework designed to ensure transparency, trust, and user protection across devices, apps, and networked environments.

### Core Principles
- **Transparency** — All logic, behaviour, and data flows are openly documented.  
- **Auditability** — Anyone can inspect the source to verify that it does exactly what it claims.  
- **Safety by Design** — Every component is engineered with privacy, protection, and user agency at its core.  

---

## Why AGPLv3?

The GNU AGPLv3 license guarantees:

- The project remains open‑source forever  
- No one can create a closed, proprietary fork  
- Any modifications — including hosted services — must publish their source  
- The community can always audit the system for safety and integrity  

This prevents the project from being repurposed into a black‑box commercial product.
