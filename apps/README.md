# Product applications

The four folders here are the long-term product boundaries. Cross-product data shapes belong in `../contracts`; reusable policy logic belongs in `../shared`; runnable demonstrations belong in `../proof-of-concept`.

The product flow is:

1. Identity and minting creates an authorised Avatar.
2. Site integration presents that Avatar to a participating service and enforces the returned decision.
3. The home app owns preferences, family membership, consent, and parental controls.
4. The mobile app authenticates the user and exposes approvals, denials, and site activity.
